# 三家出版社生字資料庫與逐字學習驗證

日期：2026-11-03（Asia/Taipei）。南一優先，再依序驗證康軒、翰林。

## 入口與使用

教師後台新增「三家出版社生字資料庫」。可依出版社、1–6 年級、上下學期及課別選生字，每批 1–8 字，按「開始逐字學習」在後台保留選單並預覽原本的六幕。返回時保留冊別、課別與選字，課內超過八字可選下一批。

沿用 public/handwriting-curriculum.json 的教育百科快照：36 冊、408 課；115 學年度上學期、114 學年度下學期。各課保留官方來源，不包含課文全文。

## 教材組成與界線

- 字典：讀取既有教育部《國語辭典簡編本》2014_20260929。注音保留全部讀音，不自選一個音當作課文讀音。單一條目且符合收藏長度上限時保留全文；多條目或超長時引導至下方完整官方釋義，沒有裁切原文。官方詞目保留原始釋義與授權，未生成白話或例句。
- 造詞：使用含該字的二字官方詞目，最多六組，排除重字；超過備份欄位長度的完整釋義不收為造詞快照。不截斷原文，不將詞義冒充單字在課文中的意思。
- 結構：使用既有 CJKVI IDS 候選，只解析明確可解析的結構；不明資料保持 unavailable。包圍／重疊不強行做左右拆合；候選仍需教師核對。來源與 GPLv2 說明沿用 public/structure-review/NOTICE.md。
- 筆順：沿用教育部原版 iframe 的既有白名單；不宣稱已逐字驗證外部網站連線。不將手寫測試字形當作教育部標準字形。
- 每批選字當成各自獨立生字，不將八字連串當成一個語詞。課文語境、白話教材、多音與部件教學仍需審定。

## 自動測試

src/curriculumLearning.test.tsx 依南一、康軒、翰林順序，對每出版社 12 冊的全部不重複字建立字卡，驗證六幕講稿、結構圖伺服器渲染、備份讀回及資料長度。另檢查多音、重字去重、八字上限與課本來源驗證。

南一：137 課、2,192 字；康軒：135 課、2,231 字；翰林：136 課、2,212 字。出版社間有重複字，不能直接相加為全域字數；全域仍為 2,973 字。

195 項單元測試通過。191 項為先前功能與手寫資料庫測試，新增四項包含全量字卡測試。每次測試產出 .local/curriculum-test-report.json；確認結果後複製至 public/curriculum-test-report.json。瀏覽器另有 36 冊第一批代表字、216 分鏡的操作結果附於報告 browser 欄位。這不等於逐字真人審定。

```powershell
npx vitest run src/curriculumLearning.test.tsx
# 檢查 .local/curriculum-test-report.json，再更新公開報告；保留本次瀏覽器證據。
npm test
npm run build
```

## 缺漏公開

缺字典／無可解析結構／無官方筆順白名單入口／無符合條件造詞，均以計數及各字清單保留在 JSON 報告。功能不崩潰不等於資料齊全；後台以「程式檢查通過」與教材待核對分開顯示。沒有呼叫 AI 猜測缺漏。
