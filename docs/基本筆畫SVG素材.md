# 基本筆畫 SVG 素材與後台配對

來源：使用者提供 `繁體中文33基本筆畫SVG_黑體版.zip`，匯入日期 2026/11/18。
33 個原始 SVG 以固定英文檔名保存在 `public/stroke-svg/`；名稱與檔案對照為 `src/strokeSvgAssets.json`。保留原始 SVG 內容，不宣稱已核定所有筆形。

後台優先使用人工選擇的圖片，否則按同名及已知別名配對；手動可選「使用原有圖形」。選取只改變卡片示意圖，不更動名稱、口訣或實際書寫軌跡。需儲存單張或整份清單才會保留選擇。更換圖片後需重新核對確認。

- 橫曲鉤→橫折彎鉤；豎曲鉤→豎彎鉤；撇橫→撇折；撇頓點→撇點。
- 豎橫折→豎折折；豎橫折鉤→豎折折鉤；橫撇橫折鉤→橫折折折鉤。
- `撇挑.svg` 與 `撇折.svg` 路徑完全相同，故不自動套用撇挑原檔，保留已修正的 SVG。選單仍提供該原始素材並標示待核對。
- 橫折橫、長頓點沒有可靠同名對應，不自動推定；可人工從縮圖選擇。
- 當後台名稱被自訂修改時，請人工重新核對配圖。

素材皆檢查為 svg/title/g/path 與靜態屬性，沒有腳本、事件、外連或內嵌 HTML。選圖 API 僅允許既定素材 ID，不接受任意 URL 或 SVG 上傳內容。
