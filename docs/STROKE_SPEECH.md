# 筆畫語音

後台「全站管理與設定 → 筆畫語音」輸入一個生字，逐筆核對本站書寫軌跡、筆畫名稱及朗讀文字，試聽後勾選確認再發布。名稱可選候選值，也可自行修正；複合筆畫不可僅依軌跡自動認定。沒有預先替教師確認的資料。

- 草稿可分次儲存。儲存草稿也會撤回該字發布；學生下次載入只讀已確認版本。
- 朗讀採瀏覽器 Speech Synthesis，使用原 TTS 偏好，優先臺灣中文聲音。不同學生裝置的聲線可能不同；本版沒有錄音上傳或固定音檔。啟用按鈕由學生操作，避免自動播放限制；可隨時關閉。
- 生字動畫教室「看筆順」下方新增「筆畫語音書寫練習」，以及書寫小達人，先念「第一筆，橫」「下一筆，豎」；錯誤重播目前筆畫。
- 正式書寫競賽不預告，只有目前筆畫正確後才念名稱，例如「橫折鉤」；錯誤只說「請再試一次」，不透露筆畫名稱。原有計分及後端軌跡判定不變。
- 教育部 iframe 是外部播放器，保持原版，不監控或注入其內部動畫。本功能在本站書寫格中同步提示，不能宣稱與教育部動畫播放同步。
- 每字語音綁定整份 `public/game-strokes/{unicode}.json` 的 SHA-256；軌跡更新、筆數不符或尚未確認時，不播放筆畫名稱。設定失敗不阻止學生書寫。

## 後端與部署

`/api/structure/stroke-speech/{小寫十六進位字碼}` 的一般 GET 只回已發布資料，供學生免登入使用；`?admin=1` 需要管理者 token。POST 需要管理者 token、允許的 Origin 及 `X-Notebook-Request: stroke-speech`，並由後端讀實際筆順檔檢查筆數及摘要。

資料透過既有 quizStore 存入原本私人寫作 bucket 的 `stroke-speech/` 前綴；不建立新的公開儲存體或放寬資料庫規則。前後端須一併經授權部署，新伺服器模組已列入 Cloud Run 打包清單。正式前端仍僅部署 Hosting target `zh-tw`。

本機驗證：`npm run test:stroke-speech`、`npm run test:structure-api`、`npm run test:competition-api`、`npm run build`。瀏覽器測試已驗證後台發布流程與390px排版、競賽正確／錯誤筆畫的朗讀事件，以及練習第一筆預告；測試採語音 spy，實際發聲及教師讀音確認仍需在裝置上試聽。

## 上線入口

- 前台：筆順練習 → 選課文與生字 → 看筆順下方的「筆畫語音書寫練習」。教育部原版播放器的聲音控制仍獨立。
- 後台：功能字卡下方「筆畫語音核對與發布」，或功能選單的「筆畫語音」。
- 未核對／未發布的生字會顯示提示，語音按鈕不啟用；不會自行代替教師確認名稱。
