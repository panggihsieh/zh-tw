# 網路安全強化發布 v2.0.2

修改日期：2026/11/19（Asia/Taipei）。

本版在既有教師後端驗證、SchoolIAM PKCE/state/nonce 與 API 來源驗證之外，加入：

- 每實例記憶體限流：一般請求每來源每分鐘 6,000 次、課堂代碼查詢 300 次、SchoolIAM 60 次；回應 429 與 Retry-After。學校共用 IP 會共用限額，多實例及重啟不共用計數。
- 跨站瀏覽器請求阻擋、本機 loopback Host 驗證、網址 4,096 字元與標頭 16 KiB 上限、標頭 10 秒及請求接收 30 秒限制。
- Hosting 與 API 的防嵌入、物件與 base 限制；停用攝影機、定位、付款，保留本站麥克風。CSP 尚未使用完整 script-src 白名單。
- 課堂代碼使用密碼學亂數；非預期例外回覆通用錯誤，保留明確的驗證錯誤。
- 限流快取與設定解鎖工作階段有總量限制；忽略常見本機憑證檔。

本機驗證：64 項後端測試、371 項前端測試通過；根專案與 deploy/cloud 正式依賴 npm audit 均為 0 個已知弱點。

部署僅更新既有 Cloud Run API 與 Firebase Hosting target zh-tw，保留服務設定及環境變數。不部署舊站，不變更 Firestore 規則。

這是應用層強化，不等同完整滲透測試或邊緣 WAF。代理 IP 沿用 Cloud Run 最末轉送位址的既有信任邊界；瀏覽器標頭不能替代身分驗證。
