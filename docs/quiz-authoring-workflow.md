# 試題製作工作台模組

教師後台「試題製作工作台」功能選項及首頁字卡，路徑 `/?view=backend&section=quiz`。

## 簡易入口

預設顯示「選擇課文 → 確認課文來源 → 開始出題」。選課後自動讀取相同版本的已匯入全文，教師核對確認後，一次建立新草稿並分批製作55題。成功批次保存，可停止、接續及進入逐批審核；缺全文時停用開始按鈕。簡易入口目前只列五上、六上，五下、六下待下學期確定教材後再製作。本次只簡化操作，不調整命題難度規則。

「進階設定／匯入其他教材」保留以下完整流程與輸出選項。

## 三步驟

1. **教材來源**：選版本、課次與來源方式。可使用已匯入教材、上傳DOC／文字型PDF／UTF-8 TXT或MD（5MB內）、貼上全文，或貼Google Drive檔案／資料夾連結解析已匯入的來源。確認全文預覽及版本後才進下一步。
2. **命題設定**：選題型、難度、題庫名稱與輸出方式。依專案固定配額：字音字形10、字詞義及運用15、文意理解15、標點5、修辭5、成語5；可先製作部分類型，再補其餘類型，不把部分配額當成整課完成。
3. **輸出題庫**：設定存成獨立版本。每批5題，生成、檢查並保存；可在批次間停止與接續。輸出雲端教師待審題庫，或加下載JSON備份。每批都有原題、兩種同義題幹、四個選項、答案、解析及逐字依據，老師可進入既有編修與審核畫面。

正常每批2次模型呼叫；遇疑點最多再修正及複查各1次。失敗停止，成功批次保留。整課11批，單次走完最多44次呼叫；人工再次操作另計。AI檢查不是人工確認正確率，不自動勾選教師審核或派送學生。

## 模組邊界

- `src/quizWorkflow.ts`：輸入參數型別、檔案封裝、可接續批次執行與JSON下載。介面只負責收集參數與顯示狀態。
- `src/LessonBankBuilder.tsx`：來源／設定／輸出三張功能字卡、各階段表單、45課配額與缺額表。
- `server/quiz-sources.mjs`：檔案驗證與文字擷取、依已登記版本分課、原檔與雜湊保存、來源清單與Drive連結解析。不執行來源內指令，不透過任意網址抓取內網或擴大Drive權限。
- `server/quiz-lesson-bank.mjs`：版本、固定配額、所選類型、去重、分批保存、斷點恢復與匯出。
- `server/quiz-pedagogy.mjs`：六類命題與檢查規格；字音字形首批注音、次批字形，避免同一單音字四種詞語形成多解。
- `server/structure-api.mjs`：使用已設定的文字模型，生成、檢查、最多修正一次。格式與重複問題也納入有限修正。

## 輸入參數

| 參數 | 用途 |
|---|---|
| `lessonKey` | 既有目錄中的出版社／學年度／年級／課次識別碼 |
| `sourceId` | 已匯入教材識別碼，伺服器依課次讀取原文，不採信前端替換的文字 |
| `passage`、`sourceLabel` | 直接貼文時使用的全文及來源說明 |
| `sourceConfirmed` | 完整課文與版本確認，未確認不建立生成工作 |
| `categories` | 此次製作的題型，白名單六類且不得空白；整課配額不變 |
| `difficulty` | 易／中／難，建立版本後沿用 |
| `outputTitle` | 新題庫名稱，最多100字 |
| `outputFormat` | `cloud` 或 `cloud-json` |

檔案匯入另需 `filename`、`base64`、`grade`、`term`、`year`，及可選的來源Drive連結 `sourceUrls`。伺服器只接受核對格式及大小的檔案，保存原始位元組後擷取文字；整冊檔案依明確課次標題拆分，補充閱讀不併入最後一課。無法判斷邊界時報錯，不能猜測。

Drive連結欄目前只對應本站已匯入來源，不會自動取得任意私人Drive檔案。新來源先下載後匯入；原始連結可在上傳時一併登記。這項限制會在介面顯示。來源與教材原文只存私有GCS，不納入GitHub或public。

## 教師API

- `GET /quiz-sources`：來源摘要；不含全文或原始位元組。
- `POST /quiz-sources/import`：驗證、保存原檔、拆課並回傳可預覽內容。
- `POST /quiz-sources/resolve`：依已登記Drive檔案／資料夾ID找來源。
- `GET /quiz-sources/:id`：讀取來源分課文字，供教師核對。
- `POST /lesson-banks`：保存輸入參數與新題庫版本，不會立即呼叫模型。
- `POST /lesson-banks/:id/next`：製作所選類型的下一批，達到所選類型配額即停止。
- `GET /lesson-banks/:id/export`：題庫JSON，狀態固定標示教師待審，不包含班級名單或獨立課文全文欄位。

以上皆掛在 `/api/structure/quiz`，沿用管理者後端驗證及來源檢查；學生不可讀教材原文、建立題庫或匯出答案。
