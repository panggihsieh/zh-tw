### 朗讀逐字提示（2026-11-01）

分鏡說明、字義、已展開造詞解釋與例句、官方詞義加入黃色逐字標示。依目前朗讀文字與 Unicode 字元位置匹配，不修改官方原文；支援分段換行、暫停保留、拖曳定位、停止清除。原生 boundary 事件搭配既有估計進度，未提供逐字事件的音色可能有時間差，不宣稱精確音訊對齊。160 項測試及正式建置通過；瀏覽器確認官方詞義標示「仔」、定位到「蹲」，停止後清除。

### 朗讀字放大（2026-11-01）

目前朗讀字以 transform 放大 1.35 倍，避免改變行寬造成文字重新排版；系統減少動態效果時保留黃色提示並取消放大。建置與瀏覽器實測 transform matrix(1.35) 通過。同步能力仍依原生 boundary／估計進度，不宣稱逐字精準對齊音訊。可評估 Azure Speech SDK wordBoundary audioOffset 或 Google Cloud SSML mark timepoints，均尚未串接。

### 結構比例與 AI 後續方向（2026-11-01）

察字新增專屬教學比例 28:72（上矮下高），不再平均分區。比例依字與部件配置套用，不當作官方精確字形；其他字未設定時仍為一般示意。163 項測試及建置通過，瀏覽器確認分區高度約 65.68／168.89 px。

使用者同意必要時可使用後台 API 輔助其他結構判斷。建議流程為已核對結構資料優先，AI 對缺漏提出結構類型、部件與比例候選，後端驗證部件數量／比例範圍並保存來源及版本，人工核對後再用於教學。包圍與巢狀結構需另建資料與呈現格式，不能強塞成上下或左右。API 金鑰留在後端，不放前台。此項尚未串接，亦未呼叫付費 API；AI 候選不可宣稱為教育部標準。
