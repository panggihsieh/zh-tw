- 新增 9 項建議測試，總計 126 項通過；編譯與瀏覽器實測偵測／觀察切換、建議點選及未收錄提示通過。

- 縮短頂部朗讀進度列，左右邊界分別對齊「朗讀本頁」及重播按鈕。編譯通過，瀏覽器實測左右邊界誤差小於 0.01 px。

- 頂部朗讀列預設顯示朗讀、暫停、停止、從頭重播四個按鈕；尚無朗讀時暫停／停止停用，重播可直接從本頁開頭開始。編譯與瀏覽器重載、重播、停止檢查通過。

- 頂部 TTS 按鈕列改為靠右，隱藏該列下方的預設音色文字；音色設定仍於後台管理。正式版編譯及瀏覽器顯示檢查通過。

- 新增本機 TTS 設定後台：來源篩選、音色試聽、試聽文字、重新偵測、設為前台預設及恢復自動選擇。
- 語音清單依瀏覽器實際提供內容及 voiceschanged 更新，前台預設保存在 localStorage；指定音色不可用時退回自動並提示。
- 試聽音色與前台預設分開，獨立雲端 API 尚未串接且不能被選成可用來源。無 API 金鑰或受保護後端。
- 新增 22 項來源、偏好保存及預設／試聽隔離測試，總計 117 項通過。

- TTS 新增估計時間進度列，可點選／拖曳／鍵盤定位、暫停在所選文字、繼續及從頭重播。
- 修正原生引擎暫停後重新定位的喚醒流程；過期或暫停後的邊界事件不再移動進度。
- 新增 11 項進度、定位、重播及邊界事件測試，總計 95 項通過。

- TTS 擴充至六幕、首頁、收藏本、資源頁與對話視窗；支援暫停、繼續、停止、調速與換幕自動朗讀。
- 旁白涵蓋結構／部件、字義／白話、造詞的釋義與例句。長文分段，取消舊佇列與錯誤回復，自動播放等待旁白完畢。
- 新增 23 項 TTS 測試，總計 84 項通過。

- 筆順幕新增教育部正式嵌入播放器，可連續播放／暫停、下一畫逐筆顯示、重播與調速；保留官方非商業／禁止改作授權，不匯出外部素材。
- 依正式嵌入清單支援 6,063 字，未收錄字保留缺漏提示。六幕自動播放於筆順幕暫停，避免跳離正在看的筆畫。
- 加入 13 項來源清單測試，總計 61 項通過。

- 建立 Vite + React + TypeScript 本機前端，繁體中文、響應式介面與原創 SVG 學習角色。
- 完成逐字多選、六幕控制、部件區域示意、多音語境、造詞翻卡與想記住的詞。
- 完成 IndexedDB 本機收藏、搜尋、複習標記、刪除確認與 JSON 還原。
