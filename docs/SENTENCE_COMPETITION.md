# 一字多詞造句競賽

第一版開放南一國語五、六年級上下學期，共45課。使用既有課本生字表與教育部簡編本字典候選讀音，不提供課文全文；老師須依實際教材核對讀音。不限定多音字，學生自行想出包含指定字且符合讀音的詞語，再造一句話。

## 老師操作

1. 教師登入後，在後台選「一字多詞造句競賽管理」。
2. 選年級、學期並勾選最多6課；可自動製作候選題，再調整為每場1至8個字，核對每字指定讀音與字典詞義。
3. 設定名稱、1至60分鐘及學生Email名單；名單留白時，所有已登入且啟用的帳號均可參加。
4. 勾選已核對讀音，派送到前台。按「開始競賽」後，全場使用相同的伺服器截止時間；晚加入不延長時間。重賽需重新派送。
5. 可提前結束，或查看作答與逐題覆核。AI建議及老師覆核分開保存，學生以老師覆核為準。AI未完成的作答可補評或直接由老師評分。

## 學生操作

前台按「造句競賽」，或在遊戲專區進入「一字多詞造句競賽」，登入Google帳號後選擇競賽。看指定字與注音，自己想詞造句，可說話或打字。語音辨識結果須由學生確認；AI同音錯字建議可採用或保留，不能自行覆寫答案。每題確認送出後即鎖定。最後一題送出或提前完成後開始逐題評分。

截止時間由伺服器檢查，重新整理不會重設倒數。時間到只保留已送出答案，不會自動提交未確認草稿。可從競賽列表查看自己的已送出作答與更新老師評語。

## 配分

每題100分：適切使用成語40分；人、事、時、地、物各10分；整句順暢0至10分。成語須實際出現在原句且用法適切；人事時地物須提出原句片段作為依據。指定字或讀音用法不符為0分；有歧義、AI失敗或輸出格式不符時標為待老師覆核，不假造0分。

AI評的是文字中的語詞及指定讀音用法，不能據此確認孩子實際發音。指定注音由裝置朗讀，語音品質依裝置而異，作答以畫面注音為準。正式使用前，請在後台啟用既有AI設定並確認模型金鑰有效。

## 資料與驗證

競賽、參賽及作答透過既有私人雲端儲存體保存，API驗證登入、帳號啟用狀態、管理者權限及派送名單。學生只能取得自己的作答，不公開其他學生名單或答案。本站不保存錄音；瀏覽器語音辨識可能使用其供應商服務，AI校對及評分使用學生確認的文字。老師補充課文只供老師對照，不作為學生得分依據。

執行 `node scripts/build-sentence-bank.mjs` 可由既有教材與字典重建前後端相同題庫。`npm run test:sentence-api` 驗證配分、權限、固定截止時間、重複作答、校對上限、AI失敗及老師覆核。另以本機模擬帳號及AI完成瀏覽器派題、作答、評分、覆核流程；不等於正式真人麥克風或正式模型評分驗收。
