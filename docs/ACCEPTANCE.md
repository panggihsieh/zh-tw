## TTS 來源設定追加驗收

**117/117 測試通過（5 檔）**，含新增 22 項：明確預設優先、失效回退、中文語言識別、儲存／重載、自動模式、損壞資料、儲存受限、白名單欄位及試聽不改預設。TypeScript 及 production build 通過。

瀏覽器實測偵測到 3 個本機 Microsoft zh-TW 音色（Hanhan／Yating／Zhiwei）、0 個瀏覽器線上音色。線上篩選如實顯示沒有可用音色；Yating 試聽可發出語音請求，前台預設未變。將 Hanhan 設為前台預設後，前台名稱及重新載入保留設定均通過。

重新偵測清單仍為 3 個音色，最後版本前台朗讀可啟動。390×844 手機設定頁無水平溢出；原音色缺失、設定損壞及儲存受限分支以自動測試覆蓋，沒有改動作業系統語音配置。

這是本機瀏覽器偏好管理，不是具身分驗證的伺服器後台。Google Cloud、Azure、OpenAI 等獨立 API 服務沒有串接或實測，不列為可用預設。

## TTS 追加驗收

更新後 **84/84 自動測試通過（4 個測試檔）**，TypeScript 與 production build 通過。新增 23 項測試涵蓋六幕講稿、白話、3/6 詞語及例句、繁體語音優先、長文分段、暫停／繼續、取消舊佇列、過期事件、缺少 API 及語音錯誤。

瀏覽器實測：本幕／本頁／收藏本／資源頁／設定與匯出視窗都能發出 TTS 請求並呈現操作控制；暫停、繼續、停止、換幕自動朗讀、關閉自動朗讀及切頁取消已通過。React effect 更新需等可見狀態出現或消失後判定，未把即時快照當作最終結果。

390×844 手機版控制與速度選單無水平溢出。六組造詞的長旁白實測在原本換幕時間之後仍停留於造詞幕，保持朗讀狀態，手動停止後可正常切幕。最後版已複驗中文朗讀請求；不將瀏覽器控制狀態視為真人發音品質驗收。

這驗證的是語音請求、狀態及內容，不是對音色與實際發音的真人聽力驗收。使用裝置 Web Speech 引擎，優先 zh-TW；多音字與各作業系統音色不保證一致。教育部播放器內的字音維持獨立，TTS 不讀取或操控第三方 iframe 內容；無音檔匯出。
