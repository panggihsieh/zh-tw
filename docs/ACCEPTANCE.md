## 筆順功能追加驗收

更新後 Vitest **61/61 通過（3 個測試檔）**，TypeScript 與 production build 通過。原本 48 項結果保留於下表作為初版紀錄。

- 官方「播放」切換播放／暫停狀態；「重播」後按「下一畫」逐筆描出，已實際操作並檢查 SVG 畫面。
