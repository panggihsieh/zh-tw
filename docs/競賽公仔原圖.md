# 競賽公仔原圖

原圖保存在私人 Cloud Storage，教師 API 驗證權限後才能讀寫，不放進公開 GitHub 或 Hosting。以既有縮圖字串的 SHA-256 綁定原圖，因此班級名冊、舊課堂及現有排名保持同一公仔；不靠姓名猜圖、不修改名次或分數。

教師端即時排名、最終排名與匯出共用原圖元件。原圖載入失敗會顯示重試，匯出會等待原圖完成；失敗時阻擋匯出。未登錄原圖仍使用既有公仔。新上傳保留原始 JPEG、PNG 或 WebP 檔案，96px 縮圖僅作名冊及一般課堂資料傳遞。

本次來源為使用者指定的 panggihsieh/RAG 正式資料；以班級、座號、姓名三者唯一對應，再核對私人圖片 SHA-256。10 位匹配：9 張 1024×1536、1 張 341×512。下載與匹配清單只保留於忽略的 .local，不提交學生資料。本機準備完成不表示正式原圖已匯入；需於部署後執行版本與條件寫入的私人匯入。
