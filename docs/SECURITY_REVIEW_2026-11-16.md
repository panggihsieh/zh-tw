# 安全強化與驗證紀錄

日期：2026/11/16（Asia/Taipei）。本次修改先在本機驗證；此文件不是正式站已部署的證明。

## 本次修補

- Kahoot 四碼代碼改用 `node:crypto.randomInt`。保留四碼及教師開賽後鎖定加入的規則，學生仍免登入。
- 在權限及資料庫查詢前加入每個服務實例的來源限流：每來源每分鐘一般請求 6,000 次、課堂代碼查詢 300 次、SchoolIAM 登入 60 次。超過回 429 與 Retry-After；限流鍵不依 Cookie，因此清 Cookie 不會重設這一層限制。資料庫原有錯三次鎖定十五分鐘的檢查仍保留。
- 限流快取最多 10,000 個項目；滿載時拒絕新項目，不無限擴充。過期設定解鎖工作階段會清除，並限制總量。
- API 拒絕瀏覽器標記為跨站的呼叫，並保留各子服務原有 Origin、專用請求標頭與教師後端驗證。這些瀏覽器標頭不是身分證明，不取代權限檢查。
- 本機 API 在派送子服務前驗證 loopback Host，降低 DNS 重綁風險。
- 一般 HTTP 請求本文接收限制 30 秒、標頭接收限制 10 秒、標頭大小限制 16 KiB，網址長度限制 4,096 字元。原有本文大小上限維持。
- 正式 Hosting 與 API 加上 X-Frame-Options: DENY，以及 CSP 的 frame-ancestors、object-src、base-uri 限制；權限政策停用攝影機、定位與付款，保留本站麥克風。
- 課堂服務非預期錯誤不再將內部例外訊息傳回學生；子服務意外拒絕改回安全錯誤，避免未處理的 Promise 拒絕。
- Git 忽略本機環境設定變體及常見私鑰／憑證檔案。部署仍使用明列伺服器檔案，不打包 `.local` 或 `.env`。

## 已驗證

- `node --test server/*.check.mjs`：60 項通過，含 10 項新增安全測試。
- `npm test`：257 項通過，含既有學生免登入、教師權限、麥克風及語音事件測試。
- `npm audit`（根專案，含開發依賴）及 `npm audit --prefix deploy/cloud --omit=dev`：均為 0 個已知弱點。
- 掃描目前 Git 追蹤的可讀文字檔（單檔不超過 2 MB），未發現符合高可信度私鑰、GitHub Token、常見供應商 Secret 及服務帳號私鑰模式的項目。不輸出任何疑似金鑰原文。
- 檢查應用程式／伺服器動態程式執行入口；未發現 `eval`、`new Function` 或將學生內容拼入 shell 指令的路徑。既有 DPAPI 子程序使用固定腳本，資料以標準輸入傳入。

## 範圍與限制

- 這是程式碼與本機測試結果，不是完整滲透測試、供應鏈鑑識、Git 全歷史掃描或雲端帳號權限稽核；不能據此保證不存在後門或未來攻擊。
- 來源限流是每個 Cloud Run 實例的記憶體防護，重啟會重設，多實例不共用；不取代邊緣 WAF／DDoS 防護。共享學校 IP 會共用限額。雲端沿用服務現有最末代理 IP 的信任邊界，部署後須確認實際代理鏈與限流紀錄；不信任 X-Forwarded-For 的第一個自填值。
- CSP 目前限制嵌入、物件與 base，尚未採用完整 script-src 白名單，不宣稱已完整阻止 XSS。完整腳本 CSP 須另測 Google 登入、Drive、PDF worker 與 SQL.js WebAssembly。
- 四碼加名冊姓名的免登入模式，無法像個人帳號驗證那樣證明學生本人身分；不能消除知道代碼者選取他人姓名的風險。
- Firestore 規則檔為既有專案的合併片段，本次未覆蓋正式規則、IAM、服務帳號、網域、金鑰或環境變數。
- 正式前端未獲提交／部署指示前不發布；未來部署僅使用 Hosting target `zh-tw`，不發布舊站。後端安全修補需要另部署既有 Cloud Run 服務，不能只發布前端。
