## 一至六年級、三出版社對照

已從教育百科公開字表擷取三家出版社共 36 冊（康軒／南一／翰林 × 1–6 年級 × 上下學期）、408 課。上學期使用 115_1，下學期使用 114_2，非同一學年上下冊。`public/handwriting-curriculum.json` 保留來源及年度快照；每冊仍待教師核對與課本版本相符，筆順有資料不代表符合臺灣標準。

各冊索引來源為 `https://pedia.cloud.edu.tw/Bookmark/Textword`，每課保留 `TCollection?TextNameId=...` 原始來源。只有單字生字，未收錄課文全文或圖片，沒有採用雄筆順的課本資料。完整字表與筆順覆蓋是兩件事：字形庫缺字在介面逐冊列出，不用異體、簡體或 AI 猜測替代。

字表共含 2,973 個不重複生字，其中 2,951 字有本次開放筆順，22 字缺少；介面依冊列出缺字。這不等於 2,951 字都已符合臺灣標準。

可另選出版社、年級、學期後貼上生字建立本機課別，每課最多 500 個不重複字。

## 書寫與檢核程式流程

1. 讀取 catalog.json；查所選生字是否有檔案，缺字直接顯示未收錄，不做簡繁替換。
2. 載入單字 strokes SVG 輪廓與 medians 筆畫中心線。ResizeObserver 依容器調整畫布，同一正方形座標縮放。
3. 播放連續或單筆示範。進入示範會取消檢核；「開始手寫檢核」重新由第一筆開始。
4. Hanzi Writer 收集滑鼠／觸控輸入，對目前應寫筆畫檢查形狀、位置、方向與順序。固定不接受逆向筆畫，不因錯誤太多自動放行；錯三次顯示提示。這是路徑容差比對，不使用 AI，也沒有書法美感或握筆姿勢判讀。
5. onMistake 顯示目前筆號、錯誤次數；onCorrectStroke 更新剩餘筆畫；onComplete 才寫入完成紀錄。
6. 切字、描紅模式、離開工具、清除重寫會取消原檢核；不將未完成練習記成完成。

## 本機後台資料庫

- IndexedDB 名稱 hanzi-notebook-handwriting，獨立於收藏資料庫。
- courses：出版社、年級、學期、課名、生字、更新時間。
- attempts：生字、參考筆畫數、未符合次數、描紅模式、完成時間、資料版本。
- 不保存姓名、手寫軌跡或 API 金鑰；沒有串接 Firestore，也不修改現有 Firebase 規則。
- 課別及完成紀錄可匯出 JSON。目前提供匯出，尚無此格式的還原介面；換電腦不會自動同步。
