# 網站樣式資料庫

後台「網站樣式資料庫」可選擇現有樣式、新增副本、調整配色與圓角、預覽、儲存及套用全站。
第一個樣式「森林冒險」以使用者提供的參考圖為準，採綠色導覽、奶油白卡片、金色點綴與圓角。
參考圖僅作後台設計對照，不將圖中人物、關卡或獎勵數值當成真實學生資料。
學習頁新增生字探索引導；維持既有選課與六幕操作。

## 儲存及同步

- 樣式：`hanzi_notebook_themes/{id}`。
- 目前全站樣式：`hanzi_notebook_settings/websiteTheme`，包含完整樣式快照。
- 儲存目前使用中的樣式會同步更新套用設定；儲存其他樣式不改變現行樣式。
- 前台監聽目前樣式，管理者套用後不需重新部署即可同步。
- 尚未設定或讀取失敗時使用內建森林冒險樣式；首次啟用前須合併 `firestore.hanzi.rules` 的樣式驗證函式與對應規則，保留其他規則。
- 樣式公開讀取，只有管理者可寫入。色碼僅允許六位十六進位，禁止任意 CSS 或腳本。
- 新增的參考設計可再建立樣式；新增插畫、元件結構或新字型仍需程式與素材更新，單純配色與圓角可由後台即時套用。
