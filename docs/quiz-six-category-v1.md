# 南一高年級六類出題第一版（2.0.30）

日期：2026/11/26（Asia/Taipei）

入口：`https://zh-tw.web.app/?view=backend&section=quiz`，教師登入後選「南一高年級・六類出題」。

## 使用

1. 選南一五上、五下、六上或六下與課次，再按「帶入所選課名」。清單共45課，沿用教材資料所標示的學年度，不宣稱各課已備妥全文。
2. 選已儲存班級，或填班級與學生Email；貼上／上傳有權使用的課文全文。
3. 字音字形、字詞義及運用、文意理解、標點符號、修辭、成語各自選難度與題數。預設各1題，合計最多10題；0表示不出該類。
4. 產生原創四選一草稿與每題兩個同義題幹。正常為2次模型呼叫；若有語意或格式疑點，最多額外修正及複查各1次，不無限重試。仍失敗不保存。
5. 在草稿檢視答案、解析、逐字依據及AI檢查紀錄，編修後重新審核，逐題確認後才發布至指定班級。

## 命題參考與界線

以使用者已登入的康軒雲選題畫面中「南一五上第九課：小小力量將世界照亮」為小樣本，查看字音字形、詞義、文意、修辭及成語等可見題型，整理成原創命題規格。此版未完整抓取第三方題庫，未保存第三方題幹、答案或登入憑證，也未建立自動爬蟲。標點功能判讀採獨立命題規則，不能宣稱已逐題查核第三方全部標點題。

課次目錄是生字清單，不是課文全文。此版是教師依提供課文產生草稿的工具，不是已完成45課的預製題庫。生字延伸成語須註明延伸關係，不把原創情境聲稱為課文事件。

## 驗證與限制

- 完整生成路徑的自動化測試涵蓋六類配額、兩次正常呼叫、一次修正上限、學生禁止出題、保存草稿及未審核禁止發布；模型使用明確標示的虛構回應。
- 實際文字模型小樣本以自寫助人主題短文測五、六年級，未把小樣本或AI自評換算成正確率。測試草稿放本機隔離記憶體，不寫入正式學生題庫。
- 實測發現重複選項、標點多解、選項與解析不一致等問題；格式驗證及AI複查能擋下部分問題，但AI曾漏判，教師審閱仍必要。未完成全45課的內容驗證。
- 介面以隔離測試頁檢查課次及班級帶入、題數上限、取消題型、編修後審核重置、草稿保存及手機375px無橫向溢出。此測試不等同正式帳號登入後的端到端派送。
- 建置包含SchoolIAM回呼資源與正式Firebase設定檢查；登入回呼設定未修改。
