# 全部筆畫口訣邏輯複核（2026/11/18）

本次是依使用者指定規則進行的口訣一致性檢查，不代表已逐字驗證所有筆形、例字或官方名稱。

## 判斷規則

1. 橫後第一折預設向下；豎或撇後第一折預設向右，省略該方向。
2. 第二次連續轉折保留方向，例如「右折」「下折」。
3. 平折、圓彎、上挑、撇、點分開表達，不因精簡而合併。
4. 彎後預設鉤向可省略；向下行筆後的左鉤保留「左鉤」。
5. 刪除多餘的「再」，各動作以逗號分隔；保留斜彎、微彎、平彎的差異。
6. 不使用通用字串替換改寫已儲存資料；自訂口訣保留，教師可手動帶入新版並重新確認。

## 尚需筆形核對的項目

- 「長頓點」沒有使用者指定的口訣，不自行推定為點或捺。
- 「橫折橫」目前沿用橫→下→右的示意口訣；原清單例字「凹、朵、設」可能涉及折與彎的差別，不能以此名稱將所有例字當成同一筆形。
- 「橫曲鉤」的例字含「乙、九」：各字曲線可能不同，仍須以實際筆形核對。
- 32 種表內共用符號及例字差異仍待逐字核對；名稱對照不是 Unicode 等價宣告。
