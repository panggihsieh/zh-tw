# Kahoot 最終排名與結束音效

一字多詞 AI 造句、生字結構、書寫生字與自訂 Kahoot 四選一遊戲共用結束流程。

- 課堂結束後，教師與已加入的學生可在最終排名按「拍照保存排名」，預覽後按「上傳排名照片」。也可直接下載。
- 照片包含課堂、班級、台北時區上課日期時間、設定時長、公仔與完整排名。
- 保存後可在同一課堂的「查看已上傳排名照片」取回並下載。每位使用者每堂課保留最新一張，重試不新增重複照片。
- 教師可讀取該課堂保存的照片；學生只能讀取自己的照片。照片存放於既有私人作品儲存區，不使用公開分享網址。
- 伺服器驗證課堂已結束、無進行中評量、排名版本一致、JPEG 格式及大小；排名變動時須重新拍照。
- 課堂從進行中轉為結束時播放一次鼓掌；開啟舊課堂或重新整理不補播。可關閉或按「試聽結束音效」。自動播放受瀏覽器限制時可手動試聽。
- 模擬學生可預覽結束與拍照下載，不上傳正式紀錄。

## 參考與資產

依使用者指定的 https://github.com/panggihsieh/RAG Kahoot 開課流程及排名拍照模組整合。鼓掌錄音與該專案使用同一檔案，來源及 CC0 授權見 `public/audio/README.md`。DOM 拍照使用同一版 html2canvas 1.4.1，保留 `public/html2canvas.LICENSE.txt`。

部署須同時更新 Cloud Run API 與 Firebase Hosting，才能使用新的排名照片 API。
