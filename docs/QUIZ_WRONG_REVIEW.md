# 國語母題題庫與錯題複習

## 入口與操作

- 教師：後台「國語母題與錯題管理」。先「AI 建立母題」，選三家出版社／課次，帶入課名，再貼上有權使用的完整課文。現有課次清單不包含課文全文。
- 填入班級名稱與學生 Google 帳號清單（最多100人）。只有指派帳號可看到／作答試卷；管理者可預覽所有卷。未列入名單的管理者預覽不列入班級統計。
- 按 AI 產題會使用伺服器已儲存的供應商／模型／金鑰，將課文傳送給該供應商。每批1–10題，出題與交叉檢查各一次，可能計費，不自動重試。
- 每個母題包含四個選項、唯一答案、解析、課文逐字依據與兩個 AI 同義題幹。AI 只變換題幹措辭，選項、答案、考點、否定與限制保持一致。AI 檢查只代表未發現疑點；教師須逐題檢查母題及所有改寫，才能發布。
- 可從已發布母題勾選組卷，選「原題再考」或「AI 同義改寫題」。已發布卷不可覆寫，再出卷會建立新卷並保留母題識別碼；改寫從已審版本選取，不於學生作答時額外計費產生。相鄰改寫作答避開上一份的措辭，版本有限仍會循環。
- 學生：前台「國語錯題本」（`/?view=quiz`）。Google 登入後選老師試卷作答。開始時固定題目版本，分頁重整可還原作答。答案與解析不在交卷前傳給學生。
- 交卷後伺服器批改。錯題本保留累計答錯次數、最近選答、正解、解析與依據；最近答對後仍保留歷史，標示「最近已答對」。可單題複習或再練該卷所有曾答錯的題，並選原題／改寫。
- 教師「查看全班錯題統計」依錯誤率排序，顯示每題答錯人數／作答人數、四選項分布、仍答錯的學生、首次答錯與最近答錯、改善人數。勾選仍有學生答錯的題即可集中再出卷。

## 統計定義

正式測驗按「母題識別碼＋學生 UID」取最近一次已交卷紀錄，避免重考次數灌大分母；首次、最近一次針對同一批本題有作答者比較。未交卷不列入分母，自行錯題複習與管理者預覽不混入全班正式統計。學生錯題本則會追蹤自行複習後是否答對。

原題與改寫共用母題識別碼。再測卷繼承同一班級、名單、課文與母題選項／答案，保留原卷與再測卷關係。這是班級練習紀錄，不是正式學校成績系統。

## 儲存與權限

資料由 Cloud Run 寫入既有 zh-tw 專用私有 bucket 中的獨立 `quiz-papers/`、`quiz-attempts/` 前綴，不更改其他站點或共用 Firestore 規則。使用 Firebase Google 身分驗證與既有停用帳號檢查。學生只能讀寫自己的作答，只有固定管理者可讀完整母題、查看全班統計與發布。

答案、解析與原題依據不在學生交卷前的 API 回應中；伺服器依開始時的試卷快照批改，重複交卷回傳第一次結果。雲端寫入使用 generation 條件避免覆蓋其他更新。沒有自動刪除學習紀錄。

第一版每次最多20題（AI新建最多10題），每次彙整最多掃描100頁、每頁20筆；達上限會回報錯誤，不默默提供不完整統計。資料量大時需改為索引／增量彙整。AI 請求若逾時不自動重送，先重新整理題庫確認是否已建立。

## 驗證

`npm test` 執行主要前端的 Vitest 測試（獨立子專案使用自己的 node:test）；`npm run test:quiz-api` 測試母題驗證、原題與改寫、權限、名單隔離、答案隱藏、固定版本、錯題與再測的完整循環、交卷冪等與最近一次統計。既有結構 API／作品 API 也執行回歸。實際 AI 與正式站驗收另記於交付記錄，不將模擬模型通過宣稱為真實模型成功。
