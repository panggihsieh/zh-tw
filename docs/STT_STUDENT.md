# 學生念字與課本查字（2026-11-03）

前台新增「念生字，找課本，一起學」。學生按「念生字找字」才啟動 zh-TW 瀏覽器語音辨識，確認候選或修改同音字後查詢，再點選來源課程進入既有六幕。亦可直接依出版社、年級、學期、課別選字，每批最多八字；學習中可按「重新念字／選課」。

字表沿用教育百科公開來源的 36 冊、408 課：南一 137 課／2192 不重複字、康軒 135 課／2231 字、翰林 136 課／2212 字。上冊為 115_1，下冊為 114_2，不宣稱與同一學年度紙本逐頁一致；各課來源保留在 handwriting-curriculum.json。搜尋多字時逐字匹配，不表示完整語詞出現在課文。

語音不作發音評分、不自動替換簡體或同音字、不保存錄音。部分瀏覽器透過網路語音服務處理聲音，並非本站 Cloud Run STT；不支援或失敗時保留打字和選課。辨識每次最多 15 秒，可停止，離開元件會取消。實際收音、中文辨識準確度仍需在學生裝置確認，不以自動測試取代真人念字驗收。

教材沿用官方辭典、字形候選與官方筆順來源，缺資料仍顯示缺漏，並非完整審定教材。課本批次字串不當成語詞，課文多音字和語境須教師核對。

驗證：全量單元測試涵蓋每冊每課每字搜尋回溯、36 冊組合、標點正規化、同音字保留、空值與無效輸入、語音錯誤提示。瀏覽器抽測三家一年級／六年級選課、查字進教室、六幕、啟停語音及響應排版。未宣稱逐字人工審定或真實語音內容辨識已驗收。

參考：[教育百科生字詞彙表](https://pedia.cloud.edu.tw/Bookmark/Textword?semester=11)、[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)。
