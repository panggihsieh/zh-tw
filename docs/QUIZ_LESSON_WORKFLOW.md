# 課文四類出題與班級派送

後台「國語母題與錯題管理」→「上傳課文・AI 四類出題」。第一版選課清單以南一五、六年級為主；舊有題卷與題型仍保留。

1. 選課並帶入課名，輸入班級及Google帳號名單，或選用已儲存班級。名單以派送當下的內容作為快照，不會因之後另存班級而改變。
2. 上傳UTF-8 TXT、MD或含可選取文字的PDF（最多10MB、30頁、12000字），或直接貼上文字。檔案在瀏覽器本機解析，請先檢查段落、標點及PDF文字順序。掃描PDF需先轉成文字，本版不提供OCR、DOCX或圖片讀取。
3. 選擇課文理解（閱讀素養）、成語、修辭、改錯與題數、難度，再按AI出題。每一所選類別至少一題；建議四類至少4題。閱讀素養參考擷取訊息、推論、統整、評鑑反思，不代表正式PISA試題。
4. AI進行出題及交叉檢查兩次模型呼叫，使用既有API設定，可能計費；失敗不自動重試。沒有成語、修辭等足夠題材時提示不足，不得憑空補寫。不合格式、選項重複或答案有疑點的批次不入庫。AI檢查通過仍需老師逐題核對。
5. 題庫可依課別、班級或試卷名稱查找；試卷內依題型、難度、待審／已核可篩選。可改題幹、選項、答案、解析、課文依據、難度及閱讀歷程。修改後自動取消該題核可。儲存草稿保留全部母題，派送只選勾選的題目，發布時另保留原母題資料。
6. 設定班級名單、選填作答截止時間及是否打亂選項，逐題核可後按「審核完成並派送班級」。學生Google帳號必須符合名單。已發布版本不可覆寫，要再出題請使用既有再測功能。
7. 學生在國語錯題本的國語測驗看到試卷。作答前不傳送正解；交卷依核可答案批改。未交卷逾期不能交卷，已交卷結果可重載；錯題複習不受原測驗截止時間限制。
8. 老師查看全班錯題統計及各題型答對率。以各學生最近一次正式作答為準，練習不混入統計；打亂選項仍映回原始選項位置。各類能力以該類已答題次數加總計算。

驗證包含API權限、班級名單、四類出題、選項順序與批改、試卷快照、期限及錯題流程；另使用真實已設定模型與自編課文完成四類出題，透過本機模擬登入測試教師審題派送、學生批改與複習，不會建立正式學生測驗資料。
