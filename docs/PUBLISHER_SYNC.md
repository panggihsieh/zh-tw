# 出版社教材即時更新

後台「國語母題與錯題管理」→「三家出版社 AI 網路國語教材抓取更新」。管理者 Google 登入後才能操作。

## 操作

1. 「AI 即時抓取更新三家國語教材」會重新下載三家官方入口，呼叫已設定的伺服器端 AI 盤點，再下載已登記的官方教材並比對內容。每次操作都有新的時間與結果，並非固定的 AI 示範報告。
2. 登入限定教材先在出版社正式網站確認檔名與下載來源，再匯入 JSON 清單。本站不保存出版社帳密、cookie 或驗證權杖。AI 盤點入口不等於取得教材全文，也不會繞過登入。
3. 南一五、六年級教材依「年段／學期」與「課別」選擇，年段同時標示實際學年度，避免跨版本混用。預設只選本冊第一課；可指定某課，或明確選「本冊全部課別」。按下「AI 建立所選課別母題草稿」只製作已下載、最新版取得成功且尚無草稿的所選課別。已有草稿不重製；未下載、來源更新待取得與下載失敗會顯示原因。保留原題、選項與答案，AI 產生兩種同義題幹及解析，再執行語意檢查；不合格不入庫。
4. 草稿需教師逐題檢查後才可發布。教材更新不修改既有試卷、學生作答或錯題紀錄。

批次逐課執行並即時保存結果。關閉頁面會停止後續請求；重新開啟可依已保存狀態繼續，不會重製已有草稿。「本課完成後停止」會等待目前請求完成。此版本不是離線排程器。

## 按課查核（2026-11-09）

所選課別會直接列出製作狀態與「另開視窗檢視查核」。連結以新分頁／視窗開啟（由瀏覽器設定決定），主頁保留選課及批次進度。教師登入後直達該份草稿，顯示原題、同義改寫、四個選項、正解、解析、來源依據及審核欄位，可對照官方原卷並手動儲存；不自動勾選審核或發布。查核視窗不顯示教材抓取與其他試卷列表。

查核入口為 `/?view=backend&section=quiz&paper=<草稿UUID>`，沿用管理者登入及既有 API 權限，不在網址放課文、答案或驗證權杖。即使另一分頁目前停在其他後台功能，新連結也會正確進入母題查核。

篩選與查核連結更新不需要重新下載教材或再次呼叫付費 AI。驗證使用合成來源模擬單課／整冊請求，正式站以既有草稿驗證新分頁讀取；來源檔、題目與答案不新增至 GitHub。

## 更新判定

保留每次原檔 SHA256 版本、文字 SHA256、來源網址、時間、頁數、原尺寸與 PDF 旋轉資訊。文字僅 NFC、換行與首尾空白正規化；不移除標點、數字或否定詞。

- `kind=lesson`：取得完整課文後才可判定課文全文一致。
- `kind=assessment`：只判定題卷是否一致，明示尚未取得課文全文。
- 新學期同課來源可重新登記；保留舊雜湊，直到最新來源下載成功才比較。失敗、登入頁、無文字層、格式不明均不得當作未變更。
- 原始檔版本保存在私有 `publisher-originals/`，索引在 `publisher-index/`，入口 AI 報告在 `publisher-discovery/`；均沿用既有私有 GCS 儲存與管理者 API 驗證。

## 首批來源範圍（2026-11-08）

南一官方 NaniBox：115 上五年級12課、六年級12課；114 下五年級12課、六年級9課，共45份教用隨堂卷。上下冊學年度不同，不能標示為同一學年度完整教材。這些是評量卷，並非課文全文。

解析得到44課、246道獨立四選一候選題。五上第7課原卷為共用選項配對，本版不猜測轉成獨立題，列為待處理。候選數不等於已通過 AI 檢查的母題數。

正式雲端首輪實跑：45份下載成功，25課共132道母題建立待審草稿，每題含2個同義改寫；其餘20課因格式或 AI 檢查疑點未入庫。已將雲端草稿逐題比對本機原卷解析的題幹、選項與答案，132題一致，全部未發布、未代勾教師審核。這是版本保真與格式驗證，不是人工課文正確性審定。

康軒、翰林已有官方入口即時 AI 盤點功能；是否取得教材，須以後台實際登記／下載結果為準。不可把入口報告當作已下載題庫。

## 來源清單與離線保留

JSON 格式（URL 必須是實際確認的官方 PDF 直連）：

```json
{"items":[{"publisher":"南一","grade":5,"term":"上","year":"115_1","title":"第1課教材.pdf","url":"https://storage.googleapis.com/onebox3/confirmed-file.pdf","kind":"assessment","confirmedListing":true}]}
```

URL 只接受允許清單的 HTTPS 主機與路徑；拒絕驗證參數、帳密、任意主機與重新導向。PDF 限8MB、30頁，無文字層轉待 OCR／人工核對。目前登記範圍為五、六年級。

本機備份：`node scripts/cache-publisher-resources.mjs registry.json .local/publisher-sources`。原檔、教材文字、來源清單與執行結果留在 `.local` 或私有雲端，不提交 GitHub。

## API 與驗證

`/api/structure/quiz/resources`：GET 索引；`/register` POST 登記；`/discover` POST 單出版社即時 AI 盤點；`/discoveries` GET 報告；`/{id}/update` POST 下載比對；`/{id}/draft` POST 建立南一待審草稿。

題卷來源使用 `sourceKind=assessment`，交卷前學生不會收到含教用答案的來源文字。母題原卷來源、版本及核對狀態供教師查看。AI 通過不代表教師已確認正確，不自動發布。

檢查：`npm run test:publisher-sync`、`npm run test:quiz-api`、`npm test -- --run`、`npm run build`，並在瀏覽器實測雲端下載與 AI 母題生成。
