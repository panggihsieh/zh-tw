# 生詞遊戲與書寫作品

2026-11-08，Asia/Taipei。

學生入口：`https://voltaic-circuit-511310-a3-zh-tw.web.app/#games`。
教師入口：`/?view=backend` →「遊戲作品與評分」。沿用原 Google 登入與固定管理者；停用帳號無法讀寫作品。

## 使用方式

登入 → 選出版社、年級、學期、課文與最多八字 → 書寫小達人。可描紅、下一筆提示、退回上一筆、清除本字或觀看教育部原版示範。寫對的原始軌跡為藍色，需要重試的軌跡為橘色，都保留在畫面與圖片；不替換成標準字。每字最多 100 次筆畫紀錄，達上限可清除該字重練。

草稿以 UID／課文／字組隔離儲存於 IndexedDB，可返回後恢復。清除瀏覽器資料會清除尚未繳交的草稿。全部生字完成後可預覽並繳交。以程式產生整份 PNG，包含字跡、課別、各字完成與重試次數，不擷取螢幕或相機。只有伺服器確認成功才顯示已繳交；失敗保留草稿、允許重試。相同 ID 的重送不建立重複作品。繳交後再修改會產生新作品 ID。

老師可依姓名、信箱或課文搜尋已載入的作品，分頁載入、放大檢視圖片、下載原圖、查看逐筆順序，以 0–100 整數分與最多 1000 字評語批改。學生在「我的作品與評語」查看。教師只有固定管理者；尚無多教師、班級名冊、派作業與跨班授權。

## 資料與檢核

來源是 `g0v/zh-stroke-data` 固定 revision `26f12d65063cc97d2773b7777232277bfca5f563` 的原始 outline／track，來自教育部筆順字形。完整來源與其授權說明保留在 `/game-strokes/SOURCE-LICENSE.md`，不得將整套資料誤標 CC0；原 README 明確區分字形資料與程式授權。本專案依使用者指定作非營利教育用途。不使用 gsyan 程式或未確認的部件表，不需執行或安裝 REA；此網頁已有可直接分析的公開資料與程式。

資料共 4,847 筆；課本 2,973 個不重複字中有 2,900 字可用，73 字缺少，選課時顯示且停用。不以其他來源字形替代。保留既有 Hanzi Writer 後台測試，但新遊戲不使用其字形作檢核。

檢核按筆順逐筆比較：等距取樣、起終點、方向、位置、形狀及長度容差。這是自建教學輔助演算法，非教育部認證或書法評分。來源是固定舊版資料，可能與現行教育部內容有差異；保留官方原版播放器供教師核對。未宣稱逐字人工確認或具有特定辨識正確率。字跡品質由教師評分。

## 後端與存取

沿用 Cloud Run `zh-tw-structure-api`，新增 `/api/structure/writing/*`；所有操作驗證 Firebase Google ID token、專案、期限、email_verified 與使用者停用狀態。寫入檢查本站 Origin 與專用標頭。學生只能讀自己的作品，只有教師可讀全部及評分。學生提交的 UID／email／分數會被忽略；身分與時間由伺服器加入。

獨立 bucket：`voltaic-circuit-511310-a3-zh-tw-writing`，位於 ASIA-EAST1，uniform access、public access prevention enforced。只授權原 runtime service account 操作該 bucket，不修改其他資料庫規則。作品圖片與筆畫放在私有 JSON 物件內，沒有公開圖片 URL；透過受保護 API 讀取。列表每次最多 20 件，圖片於點開後顯示。評分使用物件 generation 防止並發覆寫。

## 驗證與發布

`npm test`、`npm run test:writing-api`、`npm run test:structure-api`、`npm run build`。
資料測試逐筆檢查來源格式與原始軌跡通過，另測反向、錯位置、錯筆順、短筆畫；不是實際學生字跡正確率。
HTTP 整合測試涵蓋匿名／停用拒絕、跨學生讀取、學生評分拒絕、CSRF、重送、衝突、分頁與教師評分。
瀏覽器本機測試頁只放在忽略的 `.local/`，不納入正式發布；測試帳號與模擬錯誤不出現在產品。

正式發布依 `docs/FIREBASE_DEPLOY.md`：先部署 API，再 build 與指定 `hosting:zh-tw`；不部署其他 Hosting 站點。實體 iPad／觸控筆及大班同步使用仍待實機驗收。

新增其他遊戲時，擴充 `GameZone.tsx` 的可玩遊戲清單，沿用登入、課文與生字選擇；不同類型的作品資料另行定義，不把尚未實作的遊戲顯示成可玩項目。
