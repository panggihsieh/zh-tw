# 真人鼓掌音效

`applause.mp3` 為真人群眾鼓掌錄音，來源為 Amada44 的
[Sound Effects - Applause after a concert](https://commons.wikimedia.org/wiki/File:Sound_Effects_-_Applause_after_a_concert.ogg)。
原作者採用 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 授權。

由原始錄音第 2 秒起擷取 3 秒，加入 0.1 秒淡入與 0.5 秒淡出，
轉為 44.1 kHz、雙聲道、128 kbps MP3。學生喝采、完成練習與老師鼓掌按鈕共用此錄音。
