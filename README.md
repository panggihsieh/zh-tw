# 生字動畫收藏本

臺灣繁體中文生字學習前端。輸入語詞、逐字選取、六幕教學、本機收藏及 PNG／PDF／JSON 匯出。提供本機 TTS 設定後台（瀏覽器偏好設定頁），尚未建立伺服器或教師管理後台。

## 本機使用

需要 Node.js 22.12 以上（目前以 Node.js 25.2.1 驗證）。PowerShell：

```powershell
Set-Location K:\CODEX\zh-tw
npm ci
npm run dev
```

開啟 <http://127.0.0.1:5173/>。使用相同的網址及瀏覽器才能找到原本的 IndexedDB 收藏；`localhost` 與 `127.0.0.1` 是不同儲存空間。

亦可雙擊 `啟動生字收藏本.cmd`，自動檢查套件、建立正式版、在背景啟動本機服務及開啟瀏覽器。已有服務時直接開啟，不重複啟動。服務只綁定 127.0.0.1，不開放區網。重新開機後再點一次即可。

## 功能

- 1–8 字輸入與多選；保留重複字的位置、語詞語境與獨立字卡。
- 「試試看」依輸入即時推薦同字詞語，不需先送出；候選來自內建語詞、造詞及少量選詞提示，沒有外部 AI 查詢。部分候選尚未收錄完整語境教材，選取後會如實提示。
- 六幕：認識生字、結構示意、部件示意、官方筆順動畫／逐筆顯示、語境字義、一字多詞。
- 上下一幕、切字、播放／暫停、重播、慢中快、朗讀、注音與字幕、減少動態。
- TTS：六幕皆可「朗讀本幕」，字義與白話依目前選擇朗讀；造詞包含解釋與例句。首頁、收藏本、資源頁可「朗讀本頁」，設定／下載／雲端等視窗可「朗讀視窗內容」。提供暫停、繼續、停止與慢中快；朗讀速度與教室播放速度共用設定。
- 勾選「切換分鏡時自動朗讀」後，手動換幕也會朗讀；自動播放會等旁白結束再計時換幕，切頁或關閉視窗會取消舊旁白。長內容分段排隊，避免一次送出過長文字。
- 朗讀後顯示進度列及估計時間；點選、拖曳或用方向鍵定位後會先暫停，按繼續從對應文字接續。可按「從頭重播朗讀」回到開頭。Web Speech API 不提供音檔式精準秒數 seek，因此不是精確音訊時間軸；位置以文字計算，時間依字數與語速估算，收到語音文字邊界事件時同步位置。
- 「銀行／行走」依語境顯示不同讀音；未收錄的語境不猜讀音。
- IndexedDB 收藏、字詞搜尋、複習狀態、刪除前確認、JSON 備份匯入。
- 單字 PNG、每字一頁的語詞 PDF、含語境與分鏡快照的 JSON。
- 官方查字資源連結，沒有教師登入或受保護的管理端。
- 「TTS 設定後台」顯示瀏覽器實際提供的中文音色，依 `localService` 分為裝置本機及瀏覽器線上語音。可篩選、試聽、重新偵測、設為前台預設或恢復自動選擇。試聽不改預設；前台顯示預設名稱。設定只保存於目前瀏覽器 `localStorage`，重開後讀回。

## 資料限制

內建少量教材：感謝、謝謝、銀行、行走、觀察。白話、造詞、注音與結構示意標為待教師審定。來源與查核範圍見 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。

**筆順幕使用教育部正式嵌入播放器。** 在播放器按「播放」可連續觀看／暫停，按「下一畫」一次看一筆，可調快中慢及重播。依官方公開嵌入清單收錄 6,063 個字碼，不猜測未收錄字的網址；未收錄字顯示缺漏。需連線使用，非商業學習限定，保留原版內容與授權。六幕自動播放到筆順幕會暫停，完成後按下一步繼續。主時間軸速度不控制官方播放器，請用播放器內的快／中／慢。

外部筆順不納入 PNG/PDF/JSON 素材或影片匯出；本機仍沒有重新製作官方筆畫路徑。部件動畫是字型區域的分離示意，不能當作標準字形拆解、字源或筆順。

PDF 以瀏覽器 Canvas 轉成逐頁圖片，確保繁體字顯示；PDF 內文字目前無法選取搜尋。PNG/PDF 不含外部網站素材。

## Google Drive（選用）

前端已提供 GIS OAuth token model 與 Drive `drive.file` 上傳流程，沒有後端。須由專案擁有者建立 Google Cloud OAuth Web 用戶端、啟用 Drive API 並設定允許的 origin，將 `.env.example` 複製為 `.env.local`，填入 `VITE_GOOGLE_CLIENT_ID` 後重啟／重建。

只按「Google Drive」才載入 GIS，只按「Google 授權並上傳」才請求授權；token 只在該次函式執行記憶體中使用。不保存 token，不要求讀寫整個 Drive。以應用程式標記找回專用 folderId，每次上傳建立新的子資料夾並回傳檔案連結。失敗可重試，部分已上傳的檔案保留在上次子資料夾，不覆寫或清除。

**未設定 client ID 時如實顯示未啟用；真實 OAuth／帳號／學校政策／上傳尚待實機授權測試。** 自動測試中的 Drive API 是模擬，不表示真實雲端測試通過。

## 檢查與建置

```powershell
npm test
npm run build
npm run preview
```

`npm run build` 先執行 TypeScript 檢查，再產生 `dist/`。Vite 相對 base 可用於靜態託管；此階段僅本機啟動，未發佈網站。詳細驗收記錄見 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

本專案未加入追蹤分析、姓名欄位或 AI 金鑰。筆順幕會載入教育部第三方頁面，其網路連線及分析工具由該網站管理。收藏只在瀏覽器，清除瀏覽資料前請下載 JSON。

TTS 使用瀏覽器 Web Speech API，優先採用後台指定的可用音色；自動模式優先 zh-TW，其次使用裝置可用的中文語音。指定音色失效時會提示並暫用自動模式；沒有中文語音時不保證朗讀效果。多音字讀法、音色及是否連網由系統語音引擎決定，本機前端不含雲端 TTS 金鑰或音檔下載。教育部 iframe 內的字音仍由其「聲音」按鈕控制，本頁 TTS 只朗讀筆順操作說明，不能跨來源控制或混音。

## 重新整理保留狀態

同一分頁重新整理時，會從 sessionStorage 還原目前頁面、輸入與選字、未收藏的學習卡、字卡與分鏡、白話模式、造詞翻卡、搜尋篩選、學習設定及捲動位置。TTS 設定頁也保留未儲存的音色選擇、來源篩選與試聽文字。

朗讀保留文字位置並暫停，按「繼續朗讀」才恢復；動畫也維持暫停。此功能不保證關閉分頁後還原，正式收藏仍請使用收藏及 JSON 備份。教育部外部播放器內部的逐筆進度無法還原，不保存 OAuth 權杖或重送上傳動作。

## 官方詞語資料

認識生字與語詞中的意思兩幕會依目前語詞顯示教育部《國語辭典簡編本》官方注音、完整詞義與例句，可按「朗讀官方詞義」。本機附帶 2014_20260929 版 45,178 筆詞目；首次進入相關幕時載入約 10.8 MB，並非即時同步 API。國教院詞語分級按鈕會帶入目前語詞開啟官方查詢。官方詞義與本專案自編的逐字語境教學分開呈現，完整授權及重建方法見 docs/DATA_SOURCES.md。

朗讀提示：分鏡說明、字義、展開詞卡與官方釋義會以黃色標示目前朗讀字。暫停保留、停止清除；音色不提供逐字事件時使用估計進度，可能與實際發音略有差距。第三方筆順播放器不受此提示控制。
