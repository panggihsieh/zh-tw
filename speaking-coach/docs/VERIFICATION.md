# 驗證紀錄

日期：2026-11-08（Asia/Taipei）。範圍：獨立 `speaking-coach` 功能，不修改父專案介面或既有 API。

## 程式檢查

- Node.js 自動測試 10 項：輸入格式與長度、AI 結構驗證、正確句子沒有問題清單、傳送教學上下文、金鑰留在後端、服務失敗與無設定回報、跨來源限制、無效 JSON、過大請求與請求頻率限制。
- `npm run build`：產生可部署 Worker；`node --check public/app.js`：語法檢查。
- 不將模擬供應商測試當成真實 AI 已連線。

## 真實模型驗證

使用父專案已設定 DeepSeek / deepseek-flash，加密設定未改寫。短文字連線回傳 HTTP 200；以下真實句子請求也均回傳 HTTP 200：

| 輸入 | 結果 |
| --- | --- |
| I would like a coffee without sugars. | 修正為 without sugar，解釋不可數名詞，提供自然口說版本 |
| Yesterday I go hiking. | 修正為 Yesterday I went hiking.，指出過去式 |
| I went hiking yesterday.，重說目標 Yesterday I went hiking. | 接受不同語序，問題清單為空 |
| 我明天早上要和朋友去爬山。，題目為對應英文 | 語意正確，沒有硬找文法錯誤 |
| 我明天早上要跟朋友去爬山。，題目為對應英文 | 接受「跟」的自然說法，問題清單為空 |

以上只是有限範例，不是文法評分正確率，也不代表所有模型輸出都會正確。

## 瀏覽器驗證

已在瀏覽器實際操作：

- 英文情境輸入、送出、等待及成功回饋。
- 保存一筆複習、切換複習頁，重新整理後仍顯示同一筆紀錄。
- 從複習進入下一種情境，保留語言與程度。
- 切換繁體中文與雙語造句，完成英翻中真實請求。
- 「再說一次」清空輸入、顯示重說狀態並停用空白送出。
- 桌面與 390px 手機 viewport 視覺檢查，手機文件寬度與捲動寬度相同，沒有水平溢位。

重說、錄音和送出均有狀態控制；等待回覆時停用輸入，避免結果對應到已改寫的句子。
